# SofaPotatoes · Organization Profile

This repository manages the public [SofaPotatoes GitHub organization](https://github.com/sofapotatoes) profile.

- **[Organization profile](profile/README.md)** — the README displayed on the organization's GitHub overview.
- **[Profile artwork](profile/assets/hero.svg)** — source-controlled, self-hosted SVG banner.

To propose a profile change, open a pull request against `main`. The public organization overview updates when a change to `profile/README.md` is merged.

For hosting, FiveM development and business inquiries, visit the [official SofaPotatoes website](https://network.sofapotatoes.com/).
